Exploitation Summary

Exploitation process: This Windows machine is straightforward as it is vulnerable to EternalBlue (MS17-010), the infamous vulnerability discovered by the NSA and later weaponized by Russia in the devastating WannaCry and NotPetya attacks. The vulnerability resides in the SMB service running on port 445.

The flaw consists of a buffer overflow triggered when processing an SMB_COM_TRANSACTION2 request. The service miscalculates the amount of data copied into memory, and by abusing this overflow, an attacker can achieve remote code execution with SYSTEM-level privileges. Since the exploit grants immediate administrator access, no privilege escalation step was necessary.

Using the AutoBlue-MS17-010 repository, I compiled a stageless reverse shell shellcode with msfvenom, launched the exploit against the target, and obtained a shell as nt authority\system directly.

Technologies/Exploits: EternalBlue (MS17-010), SMBv1 buffer overflow (CVE-2017-0143), AutoBlue-MS17-010, msfvenom shellcode generation.

Vulnerability Background - EternalBlue (MS17-010)

This machine is vulnerable to EternalBlue, one of the most notorious vulnerabilities in cybersecurity history. Originally discovered and stockpiled by the NSA, it was leaked by the Shadow Brokers group in April 2017. It was subsequently used in the WannaCry ransomware attack and the destructive NotPetya campaign.

The vulnerability is a buffer overflow in the SMBv1 protocol (port 445). Specifically, when the server processes an SMB_COM_TRANSACTION2 request, it miscalculates the size of data being copied into a kernel buffer. By carefully crafting this request, an attacker can overflow the buffer and execute arbitrary code at the kernel level, which means running commands as nt authority\system — the highest privilege level on Windows.

Contexto de la Vulnerabilidad - EternalBlue (MS17-010)

Esta máquina es vulnerable a EternalBlue, una de las vulnerabilidades más notorias en la historia de la ciberseguridad. Originalmente descubierta y almacenada por la NSA, fue filtrada por el grupo Shadow Brokers en abril de 2017. Posteriormente fue utilizada en el ataque de ransomware WannaCry y en la destructiva campaña NotPetya.

La vulnerabilidad es un buffer overflow en el protocolo SMBv1 (puerto 445). Manipulando cuidadosamente esta petición, un atacante puede desbordar el buffer y ejecutar código arbitrario a nivel de kernel, lo que significa ejecutar comandos como nt authority\system, el nivel de privilegio más alto en Windows.
